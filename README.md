# TISH SEARCH v4 — Multi-Agent Site Analyzer

**Профессиональный инструмент для анализа и оценки веб-сайтов с использованием AI**

## 🚀 Возможности

### Основные функции:
- **Массовый анализ сайтов** по городам и категориям
- **AI-оценка дизайна и UX** через локальную модель Ollama
- **Сохранение результатов** в SQLite и Excel
- **Автоматическая фильтрация** мусорных и спам-сайтов
- **Адаптивная логика** под размеры городов (STRICT/NORMAL/LENIENT)

### Новое in v4:
- ✅ **Аутентификация пользователей** (регистрация, вход, восстановление пароля)
- ✅ **Профили пользователей** с настройками темы и языка
- ✅ **Система подписок** (Basic/Pro/Enterprise)
- ✅ **Поиск по соцсетям** (YouTube, Instagram, X/Twitter)
- ✅ **Светлая и тёмная темы** оформления
- ✅ **Мультиязычность** (Русский/English)
- ✅ **Безопасность**: CSRF, rate limiting, IP blacklist
- ✅ **Загрузка примеров** хороших/плохих дизайнов

## 📋 Требования

### Обязательные:
- Python 3.9+
- SQLite3
- Ollama с vision-моделью (qwen3-vl или llava)
- Playwright (устанавливается автоматически)

### Рекомендуемые:
- 8GB+ RAM
- 4+ CPU cores
- 10GB свободного места

## ⚙️ Установка

### 1. Клонирование и зависимости
```bash
# Установить зависимости
pip install -r requirements.txt

# Установить браузеры Playwright
playwright install chromium
```

### 2. Настройка Ollama
```bash
# Запустить Ollama сервер
ollama serve

# В другом терминале установить vision модель
ollama pull qwen3-vl
# или
ollama pull llava
```

### 3. Инициализация приложения
```bash
python init_app.py
```

### 4. Настройка окружения
Отредактируйте `.env` файл:
```env
# Обязательно измените!
SECRET_KEY=ваш-уникальный-секретный-ключ-не-менее-32-символов

# Настройки почты (для восстановления пароля)
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=True
MAIL_USERNAME=ваш@email.com
MAIL_PASSWORD=ваш-пароль-приложения

# Ollama
OLLAMA_URL=http://localhost:11434
VISION_MODEL=qwen3-vl:latest
```

### 5. Запуск сервера
```bash
python server.py
```

Откройте браузер: **http://localhost:5000**

## 🎯 Использование

### Быстрый старт:
1. **Добавьте города** в очередь (левая панель)
2. **Настройте параметры** (количество сайтов, модель AI)
3. **Запустите очередь** — система автоматически:
   - Найдёт сайты по запросам
   - Отфильтрует мусор и спам
   - Сделает скриншоты
   - Проведёт AI-анализ дизайна и UX
   - Сохранит результаты в БД и Excel

### Ключевые фичи:

#### 🔍 Адаптивный поиск
Система автоматически определяет режим фильтрации:
- **STRICT** — для крупных городов (жёсткая фильтрация)
- **NORMAL** — для средних городов
- **LENIENT** — для маленьких городов (мягкая фильтрация)

#### 🎨 AI-анализ
Модель оценивает по 10-балльной шкале:
- **Дизайн**: типографика, цвета, иерархия, контраст, современность
- **UX**: навигация, читаемость, CTA, адаптивность, интерактивность

#### 💾 База данных
- Все результаты сохраняются в SQLite
- Автоматическая генерация Excel-отчётов
- Поддержка перепроверки существующих сайтов

#### 🌐 Соцсети
Отдельная категория поиска:
- YouTube каналы
- Instagram профили
- X (Twitter) аккаунты

## 🛡️ Безопасность

### Встроенная защита:
- **CSRF токены** на всех формах
- **Rate limiting** (ограничение запросов)
- **IP blacklist** для подозрительных адресов
- **Валидация ввода** (защита от SQL-инъекций, XSS)
- **Детекция ботов** по user-agent
- **Логирование событий** безопасности

### Рекомендации для production:
1. Измените `SECRET_KEY` в `.env`
2. Настройте HTTPS
3. Используйте реальные SMTP настройки
4. Настройте firewall и rate limiting на уровне сервера

## 📊 API

### REST endpoints:
- `GET /api/db` — все сайты из БД
- `GET /api/stats` — статистика БД
- `GET /api/models` — доступные модели Ollama
- `GET /api/examples` — примеры хороших/плохих дизайнов
- `GET /download` — скачать Excel-отчёт

### WebSocket events:
- `add_city` — добавить город в очередь
- `start_queue` — запустить анализ
- `stop_scan` — остановить анализ
- `update_settings` — обновить настройки
- `save_example` — сохранить пример
- `save_scores` — сохранить оценки сайта
- `recheck_db` — перепроверить сайты из БД

## 🐛 Troubleshooting

### Ошибка: "Модель не найдена"
```bash
# Проверьте установленные модели
ollama list

# Установите нужную модель
ollama pull qwen3-vl
```

### Ошибка: "Нет соединения с Ollama"
```bash
# Запустите Ollama сервер
ollama serve
```

### Ошибка: "Playwright не найден"
```bash
# Установите браузеры
playwright install chromium
```

### Ошибка: "Port 5000 уже используется"
```bash
# Измените порт в server.py
socketio.run(app, host="0.0.0.0", port=5001, debug=False)
```
