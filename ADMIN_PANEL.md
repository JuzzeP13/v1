## 📊 Возможности админ-панели

### 1. **Мониторинг в реальном времени**

#### Статистика на главной:
- 👥 **Пользователей онлайн** — сколько пользователей активно сейчас
- ⚡ **Активных задач** — сколько анализов запущено
- 🔥 **Нагрузка CPU** — процент использования процессора
- 💾 **Использование RAM** — память в MB
- 🌐 **Запросов/час** — текущая нагрузка
- 💽 **Сайтов в БД** — общая статистика базы данных

#### Автообновление:
- Страница автоматически обновляется каждые 10 секунд
- Все данные в реальном времени

---

### 2. **Онлайн пользователи**

#### Карточка пользователя показывает:
- ✅ Статус онлайн (зелёная точка)
- 🎯 Подписку (Basic/Pro/Enterprise)
- 🆔 ID пользователя (с главного сайта)
- ⚡ Приоритет (1-4)
- 📧 Email
- 🕐 Время последнего входа
- 📊 Использовано городов сегодня
- ⚡ Текущую задачу (если выполняет)

#### Пример:
```
🟢 ivan_petrov [Pro]
ID: 123 • Приоритет: 2
📧 ivan@example.com
🕐 Вошёл: 2026-04-06T14:30
📊 Городов сегодня: 3/10
⚡ Выполняет: Анализ Москвы
```

---

### 3. **Нагрузка системы**

#### Метрики:
- **CPU Usage** — с цветовой индикацией (зелёный/жёлтый/красный)
- **RAM Usage** — использование памяти
- **WebSocket подключения** — активные соединения
- **Database Size** — размер базы данных

#### Цветовая индикация:
- 🟢 **Зелёный** (< 50%) — норма
- 🟡 **Жёлтый** (50-80%) — внимание
- 🔴 **Красный** (> 80%) — критично

---

### 4. **Управление пользователями**

#### Таблица всех пользователей:
| Колонка | Описание |
|---------|----------|
| ID | ID с главного сайта |
| Username | Имя пользователя |
| Email | Email |
| План | Basic/Pro/Enterprise |
| Приоритет | 1-4 |
| Статус | Онлайн/Оффлайн/В очереди |
| Последний вход | Время |

#### Действия:

**👁️ Просмотр:**
- Детальная информация о пользователе
- История активности
- Использованные лимиты

**⬆️ Приоритет:**
- Установить приоритет 1-4
- 1 = Low (Basic)
- 2 = Normal (Pro)
- 3 = High (Enterprise)
- 4 = VIP (вручную)

**🚫 Бан:**
- Заблокировать пользователя
- Отключает доступ к сервису
- `is_active = 0`

## 🔒 Безопасность

### Защита админ-панели:

1. **Отдельная авторизация:**
   - Не зависит от обычной системы входа
   - Свой логин/пароль

2. **Сессия:**
   - `session['admin_authenticated'] = True`
   - Можно выйти через `/admin/logout`

3. **Проверка на всех endpoint'ах:**
   ```python
   if not session.get('admin_authenticated'):
       return jsonify({'error': 'unauthorized'}), 401
   ```

### Рекомендации для продакшена:

1. **Измените логин/пароль:**
   ```python
   ADMIN_USERNAME = 'your_unique_username'
   ADMIN_PASSWORD = 'your_strong_password'
   ```

2. **IP whitelist:**
   ```python
   ALLOWED_ADMIN_IPS = ['192.168.1.100', '10.0.0.50']
   
   @app.route("/admin")
   def admin_panel():
       if request.remote_addr not in ALLOWED_ADMIN_IPS:
           abort(403)
   ```

3. **HTTPS обязательно:**
   - Не передавайте учётные данные по HTTP
   - Используйте Let's Encrypt

4. **Rate limiting:**
   ```python
   # Ограничить попытки входа
   @app.route("/admin/login", methods=['POST'])
   @limiter.limit("5 per minute")
   def admin_login():
       ...
   ```

## 🎯 Приоритетность пользователей

### Уровни приоритета:

| Уровень | Название | Описание | Влияние |
|---------|----------|----------|---------|
| 1 | Low | Basic план | Обычная очередь |
| 2 | Normal | Pro план | Обычная очередь |
| 3 | High | Enterprise | Приоритет в очереди |
| 4 | VIP | Вручную админом | Мгновенный старт |

### Как установить приоритет:

**Через админ-панель:**
1. Найти пользователя в таблице
2. Нажать "⬆️ Приоритет"
3. Ввести число 1-4
4. Сохранить

**Через API:**
```bash
curl -X POST http://localhost:5000/admin/api/set-priority \
  -H "Content-Type: application/json" \
  -H "Cookie: session=ADMIN_SESSION" \
  -d '{"user_id": 123, "priority": 4}'
```

**Напрямую в БД:**
```sql
UPDATE users SET priority = 4 WHERE id = 123;
```

```

```

#### Средняя нагрузка:

#### Высокая нагрузка:
```
CPU: 80-100% 🔴
RAM: 80-95% 🔴
WebSocket: 20+ 🔴

```

### Что делать при высокой нагрузке:

1. **Уменьшить параллелизм:**
   ```python
   settings["parallel"] = 3  # вместо 5
   ```

2. **Ограничить очередь:**
   ```python
   # Максимум 2 одновременных задачи
   if active_tasks >= 2:
       emit_status("⚠ Сервер перегружен. Подождите.", "warn")
   ```

3. **Добавить ресурсы:**
   - Больше RAM
   - Быстрее CPU
   - GPU для Ollama

```sql
SELECT * FROM users WHERE id = 123;

-- Активность сегодня
SELECT COUNT(DISTINCT city) FROM search_history 
WHERE user_id = 123 AND date(created_at) = date('now');

SELECT * FROM search_history WHERE user_id = 123 ORDER BY created_at DESC;
```

```python
@app.route("/admin/api/stats")
def admin_api_stats():
    return jsonify({
        'online_count': len(get_online_users()),
```
