# Умный Поиск Товаров и Услуг

## Что изменено
- Добавлен семантический слой поиска в `modules/search/python/product_search_intelligence.py`.
- Обновлён пайплайн `modules/chat/python/product_service.py`:
  - расширение запроса по синонимам и связанным словам;
  - нормализация и упрощённая лемматизация/стемминг;
  - многоуровневое определение релевантности (`exact`, `synonym`, `category`, `partial`);
  - скоринг и финальная сортировка результатов;
  - сохранение тегов и метаданных ранжирования в БД/Excel.
- Добавлены миграции колонок `product_results` в `core.py` и `migrate_to_postgres.py`.

## Новая архитектура поиска
1. Входной запрос пользователя -> построение `ProductSearchProfile`.
2. Профиль включает:
- `query_tokens` (нормализованные токены запроса),
- `synonym_terms` (синонимы из словаря концептов),
- `related_terms` (связанные коммерческие/категорийные термины),
- `category_hints`,
- `ollama_queries` (если включена интеграция).
3. Из профиля генерируются вариации запросов с уровнями источника:
- `exact` (исходная фраза),
- `synonym`,
- `category`,
- `partial`,
- `ollama`.
4. Каждый найденный результат DDGS получает скор:
- по типу совпадения (`exact > synonym > category > partial`),
- по пересечению токенов,
- по попаданию в заголовок,
- по совпадению города,
- с учётом source-level запроса.
5. Итог: результаты сортируются по уровню и score, отдаются топ-N.

## Структура словаря синонимов
Словарь построен по концептам (`SYNONYM_CONCEPTS`):
- концепт содержит `category`, `terms`, `related`.
- пример:
  - `footwear`: `["обувь", "кроссовки", "кеды", "тапки", ...]`
  - `phone`: `["телефон", "смартфон", "мобила", ...]`
  - `outerwear`: `["куртка", "ветровка", "верхняя одежда", ...]`

Такой формат позволяет:
- расширять словарь без изменения алгоритма;
- привязывать синонимы к категориям;
- добавлять связанные коммерческие термины.

## Уровни совпадений и ранжирование
- `exact`: точное фразовое или полное токеновое совпадение.
- `synonym`: попадание терминов из синонимного словаря.
- `category`: совпадение по категории из профиля запроса.
- `partial`: частичное пересечение токенов.

Порядок выдачи:
1. `exact`
2. `synonym`
3. `category`
4. `partial`

## Расширение базы поиска
Оценка релевантности теперь идёт по объединённому полю:
- `title`,
- `description`,
- авто-теги,
- категория,
- связанные слова.

Дополнительно в `product_results` сохраняются:
- `match_level`,
- `rank_score`,
- `tags`,
- `related_terms`,
- `search_tokens`,
- `source_level`.

## Интеграция Ollama (опционально)
Поддержан локальный генератор вариантов запроса через `/api/chat`.

Новые переменные окружения:
- `PRODUCT_SEARCH_USE_OLLAMA` (`True/False`)
- `PRODUCT_SEARCH_OLLAMA_MODEL` (название text-модели)
- `PRODUCT_SEARCH_MAX_QUERIES` (лимит расширенных запросов)
- `PRODUCT_SEARCH_MAX_OLLAMA_VARIANTS` (лимит LLM-вариантов)

Если Ollama недоступна, поиск автоматически продолжает работу без LLM-расширения.
