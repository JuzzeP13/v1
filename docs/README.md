# Документация проекта

Документы разложены по темам:

- `architecture/` — архитектура и структура проекта.
- `integration/` — интеграции с внешними системами и основным сайтом.
- `production/` — инструкции для production-развертывания.
- `optimization/` — планы и отчеты по оптимизациям.
- `features/` — материалы по отдельным функциям.
