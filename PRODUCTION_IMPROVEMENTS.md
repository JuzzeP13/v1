## 🚀 Следующие шаги для продакшена

### Критично (сделать перед запуском):

1. **Миграция на PostgreSQL:**
   ```python
   # В config.py
   SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL')  # PostgreSQL URL
   ```
   SQLite не поддерживает многопользовательскую запись без блокировок

2. **Gunicorn + Nginx:**
   ```bash
   gunicorn --worker-class eventlet -w 1 -b 0.0.0.0:5000 server:app
   ```
   Flask dev server не для продакшена!

3. **Выделенный GPU для Ollama:**
   - LLaVA требует ~4-6GB VRAM
   - При 20 пользователях — отдельный сервер с GPU
   - Или использовать облачный API (Replicate, Together AI)

4. **Redis для кеширования:**
   - Сессии
   - Rate limiting (вместо in-memory)
   - Кеширование результатов поиска

5. **Celery для фоновых задач:**
   - Анализ городов в фоне
   - Скриншоты в очереди
   - Уведомления о завершении

### Важно:

6. **Платёжная интеграция:**
   - ЮKassa для России
   - Stripe для международных платежей
   - Автоматическое продление подписки

7. **Мониторинг:**
   - Sentry для ошибок
   - Prometheus + Grafana для метрик
   - Логи в ELK stack

8. **Безопасность:**
   - HTTPS (Let's Encrypt)
   - Уникальный SECRET_KEY в .env
   - CSP заголовки
   - Защита от DDoS (Cloudflare)

## 📊 Пример нагрузки (20 пользователей)

### Basic план (15 пользователей):
- 3 города × 15 = 45 анализов/день максимум
- 30 сайтов × 45 = 1,350 сайтов/день
- 3 параллельных скриншота × 15 = 45 браузеров (пиковая нагрузка)

### Pro план (4 пользователя):
- 10 городов × 4 = 40 анализов/день
- 100 сайтов × 40 = 4,000 сайтов/день
- 5 параллельных скриншотов × 4 = 20 браузеров

### Enterprise (1 пользователь):
- Безлимитные города
- 8 параллельных скриншотов

**Итого пиковая нагрузка:** ~65 одновременных браузеров (Playwright)
→ Требуется: 65 × 500MB RAM = ~32GB RAM только на браузеры
